- Keep what wilson really uses (checked at the call sites, not only the import lines):
      parse_from_source(requested_data, source_type, lvl_theory, basis_set, base_file_loc, ...)
          wilson's only way to get data (wilson_data_obtainer). wilson passes the four DataOriginInfo
          fields by keyword; it never passes reindex_modes or linear.
      the property names: dipgrad, polgrad, diphess, polhess, cff, cff_rc, qff, qff_rc, B, coriolis,
          nc_sqrt_eigval, harmonic_states, anharmonic_states; normal_modes as now (one wilson test pins it, see N)
      CQCParse.utils.PKG_ROOT: finds CQCParse's example files (tests/evv_tester.py and two other wilson scripts)
      CQCParse.logger.setup_logger: sets CQCParse's log level (integration/test_anharm_analyzer.py)
  
  wilson imported more, without using it: the 7 classes deleted in L1 (wilson_intensities/utils/utils.py)
      and DataVault (src/wilson_suite/parsing.py, script_example.py). Those lines are gone in wilson_gv's branch
      cqcparse_cleanup (L1), not yet on wilson main. Also CQCParse.debug, deleted with the dead code: wilson
      main imports it in integration/test_termND_evaluations.py, which PR #69 deletes. Commented-out code still
      names them (wilson_intensities/tests/conftest.py, tests/evv_tester*.py): harmless.

- The dict fits wilson's contract (wilson D5): properties in au (plain derivatives in mass-weighted coordinates);
  frequencies, state energies, cff_rc and qff_rc in cm-1; mode indices first, then x, y, z; modes 0 .. n-1;
  every index order filled (symmetric in the mode indices); state energies relative to the ground state.
- Both readers return the same keys, shapes and units for the same request.
- Parser bugs are silent: a wrong unit factor still gives the right shape (C3 passed every shape and symmetry
  check). So any change that moves a number in the baseline (T2) needs a reason in the commit message, e.g.
  "qff changed: C3 fixed". Run wilson's tests too (T6): wilson's reference tests compare at 1e-12 to 1e-11
  (relative), so they show what the change does to wilson's results, and wilson's reference values may need the
  same reason.
- Physics choices are [decide] items. Write the choice here first, then code it.
- Before each delete: search the name in CQCParse, tests and wilson_gv/src. A search by name misses a name used
  only as a string (getattr, a file name).
