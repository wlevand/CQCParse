How to work
-----------
The rules of todo.txt apply. In short:
    - After each change: CQCParse's tests (todo.txt Tests) and the baseline (T2).
    - A cleanup must not move a number. If the baseline moves during a cleanup, stop and find out why.
    - A change that moves a number on purpose: give the reason in the commit message, and run wilson's tests too
      (T6). None in this cleanup did; R4 moved values by 2.5e-15 relative at most, within the baseline's 1e-12.
    - Before each delete: search the name in CQCParse, tests and wilson_gv/src. The dead-code check (Q4) follows
      names, so a name used only as a string (getattr, a file name) would be missed.
