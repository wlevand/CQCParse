# CQCParse

CQCParse is a Python package for Parsing of Computational Quantum Chemistry (**CQC**) prorgram outputs.

## Key features

- Parse Gaussian 16 output (not general, output of specific jobs with specific inputs)
  - Harmonic frequencies
  - 

## Installation

### From source
1. Get source code
2. Prepare the environment
3. Install

```
git clone git@github.com:wlevand/CQCParse.git
cd CQCParse
<make env>
pip install .
```
